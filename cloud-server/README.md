# Swallow 云同步自建参考服务器

零依赖的 Node.js 服务器，配合 Swallow 客户端的「设置 → 云同步」使用。

## 协议

| 方法 | 端点 | 说明 |
| ---- | ---- | ---- |
| POST | `/{server_key}` | 上传加密数据包（body 为密文文本） |
| GET  | `/{server_key}` | 下载加密数据包 |

- `server_key` 既是鉴权标识，也是客户端派生 AES-256-GCM 加密密钥的来源。
- 服务器**只存密文**，不接触任何明文数据。
- 密文按 `server_key` 落到 `data/` 目录，一个 key 一份数据。

## 运行

```bash
node server.cjs                 # 默认 http://0.0.0.0:8787
PORT=9000 node server.cjs       # 自定义端口

# 启用 HTTPS（需提供 PEM 证书与私钥路径）
HTTPS_KEY=/path/to/key.pem HTTPS_CERT=/path/to/cert.pem node server.cjs
```

## 客户端配置

在 Swallow「设置 → 云同步」：

1. 启用云同步
2. 服务器地址：`http://<服务器IP>:8787`（本机测试可用 `http://127.0.0.1:8787`）
3. 端口：可填 `8787`，或填 `0` 并在服务器地址里带上端口
4. 服务器密钥：任意自定密钥（多台设备用同一个 key 才能互相解密）
5. 勾选要同步的内容，选择同步策略
6. 点「立即同步」上传，或在另一台设备点「从云端恢复」

## 安全提示

- 这是一个最小参考实现，**无认证/限流**。暴露到公网前请自行加反向代理 + TLS + 访问控制。
- `server_key` 决定了加密强度：请使用足够长且随机的密钥，并妥善保管（丢失无法解密云端数据）。
